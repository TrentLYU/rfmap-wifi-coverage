# 室内 Wi-Fi 覆盖预测（RF Map）

> 课程实验项目：**只在一个房间里测几十个点，把整间房的 Wi-Fi 信号强度图还原出来。**

在一间内部 **12.643 m × 11.731 m**（套内 146.21 m²）的真实房间里采集了 **49 个实测 RSSI 点**（空房）
与 **140 个放家具后的实测点**，用本地训练的小型卷积网络，从少量实测点补全出整间房的二维 RSSI 覆盖图。
全部流程**只用局域网与本机算力**，不依赖外网、不含云端 AI。

项目按两版发布：

| 版本 | 内容 | 入口 |
|---|---|---|
| **第二版（当前交付）** | **70/30 固定划分双数据集实验**（空房 + 家具，189 点），五方法 × 两任务 + 插值/物理基线，附**离线户型信号预测编辑器** | [outputs/rfmap-70-30/](outputs/rfmap-70-30/) |
| 第一版 | 五方案跨户型泛化实验（49 点 + 1200 仿真户型），方案五 PG-MPR-UNet 最优 | 见下方"第一版实验" |

## 第二版：70/30 划分实验

代码：`rfmap/holdout_experiment.py`（训练）、`rfmap/holdout_report.py`（报告）、`rfmap/holdout_infer.py`（纯户型离线推理）、`rfmap/holdout_selfcheck.py`（独立校验）；成果与离线编辑器全部在 [outputs/rfmap-70-30/](outputs/rfmap-70-30/)。

### 数据划分（固定 70/30，两版数据）

| 数据集 | 总点数 | 训练 | 测试 | 说明 |
|---|---:|---:|---:|---|
| 空房 | 49 | 34 | 15 | 第二版实测（0.2 m 数值坐标） |
| 放家具 | 140 | 98 | 42 | 家具仅桌子、椅子为实测；其余家具为几何 + 假设遮挡参数 |

### 测试集结果（五方法 × 两任务，MAE / RMSE，单位 dB）

**两种任务**：`补全`（completion，从稀疏观测补全 RSSI 图）；`布点`（layout，仅凭户型 / AP / 家具几何预测整图）。

| 方法 | 补全 MAE / RMSE | 布点 MAE / RMSE |
|---|---|---|
| 卷积补全自编码器 AE | 4.023 / 4.504 | 3.823 / 4.317 |
| 小型 U-Net | 3.863 / 4.336 | 4.467 / 5.176 |
| 残差 U-Net | **2.142 / 2.833** | 3.317 / 3.774 |
| 散落布点 U-Net | 3.461 / 3.931 | 3.661 / 4.376 |
| 物理引导 PG-MPR | 2.576 / 3.271 | 3.387 / 3.951 |
| 基线：IDW 补全 | 2.923 / 3.662 | — |
| 基线：物理趋势（仅户型） | — | 3.557 / 3.914 |

放家具（42 个测试点）：

| 方法 | 补全 MAE / RMSE | 布点 MAE / RMSE |
|---|---|---|
| 卷积补全自编码器 AE | 2.606 / 3.186 | 2.427 / 2.892 |
| 小型 U-Net | 2.480 / 3.047 | 2.558 / 3.271 |
| 残差 U-Net | 2.213 / 2.947 | 2.333 / 2.972 |
| 散落布点 U-Net | 3.340 / 4.303 | 3.423 / 4.159 |
| 物理引导 PG-MPR | 2.439 / 3.096 | 3.255 / 3.966 |
| 基线：IDW 补全 | **1.791 / 2.304** | — |
| 基线：物理趋势（仅户型） | — | 2.186 / 2.785 |

### 如实记录的结论与局限

- **部署模型**（网页 U-Net，仅凭户型/AP/家具几何）：空房测试 MAE **4.467 dB**、五档准确率 14/15=93.33%；
  家具测试 MAE **2.558 dB**、五档准确率 42/42=100%。只统计 −70~−40 dBm 正常范围测试点时，
  MAE 分别为 **4.946 dB（11 点）/ 2.443 dB（35 点）**。
- **五档分级能力未经验证**：57 个测试点全部被预测为"非常好"（最高档），数据中没有一般/较差/很差样本；
  分类准确率与"始终猜最高档"相同。RSSI 等级不等于实际网速。
- **简单基线没有被击败**：家具版 IDW 补全（MAE 1.791 dB）优于本次五种补全网络；
  只户型物理趋势基线（MAE 2.186 dB）优于网页 U-Net。报告如实呈现，未按测试成绩偷偷换模型
  （部署模型在外部测试前由内部验证固定选择）。
- **AP 位置仍未知**：本次暂假设 (0,0)；给出实际坐标后可保持拆分重跑。
- **只有同一房间的两版数据**：新户型、移动路由器、家具材质变化均未独立验证；
  家具因果衰减未证明（两版历史 x 方向说明冲突，本次按数值 x 保留、y×11.731/12 统一对齐）。
- 偏强点全部保留并标注（空房 8 点、家具 32 点高于 −40 dBm），未删除、未用插值充当实测答案；
  推理与部署不读取测试点，外部 30% 不参与归一化、早停、参数与模型选择。
- **本次未连接 ESP32 现场复采**，未重新验证设备健康、频段、接收高度与采样时长。

### 可复查性（独立校验 217/217 通过）

- `split.json` / `frozen_selection.json` / `sources.json`：划分与来源哈希；
- `models/`：20 个训练阶段权重（补全 + 布点各 10），含归一化与训练曲线；

## 第一版实验

在一间 12.643 m × 11.731 m 的真实房间里采集 49 个实测 RSSI 点，
并在 **1200 个仿真户型**上训练五个网络方案，考察跨户型补全泛化能力，
与四种插值基线对比。报告：`outputs/RF覆盖预测实验报告.html`；离线网站：`outputs/rfmap-studio/index.html`。

### 一句话结论

**方案五（PG-MPR-UNet）是最准的方案**：在 200 个训练中从未见过的随机户型上，
未观测格点 RMSE 为 **3.916 dB**（常规布点）／ **4.768 dB**（散落布点），
两个测试集上均排第一，优于最强插值基线（对数距离趋势 + RBF 残差）**0.74 ~ 1.13 dB**；
但它只比基础 U-Net 多 **864 个参数（+0.08%）**。

### 跨户型补全精度（200 个未见过的户型，未观测格点 RMSE，单位 dB）

| 方法 | 常规布点测试集 | 散落布点测试集 |
|---|---:|---:|
| **方案五 PG-MPR-UNet** | **3.916** | **4.768** |
| 方案五 + TTA | 3.699 | 4.492 |
| 方案三 残差 U-Net | 4.124 | 5.089 |
| 方案一 卷积补全自编码器 | 4.151 | 5.139 |
| 方案二 U-Net | 4.224 | 5.059 |
| 方案四 U-Net（散落数据训练） | 4.226 | 5.174 |
| 对数距离趋势 + RBF 残差 | 4.654 | 5.896 |
| IDW 反距离加权 | 4.901 | 6.124 |
| 最近邻 | 5.397 | 6.408 |
| 零均值 RBF | 21.636 | 35.745 |

### 真实房间稀疏重建（49 点中留出隐藏点）

| 协议 | 输入 / 隐藏 | 最优方法 | RMSE (dB) |
|---|---|---:|---:|
| 中心插值 | 40 / 9 | 方案五（预训练） | **2.275** |
| 角块外推 | 43 / 6 | 方案二（实测微调） | **2.591** |

### 五个网络方案（第一版）

| 编号 | 方案 | 核心思路 |
|---|---|---|
| 方案一 | 卷积补全自编码器 | 编码器─解码器直接回归整图 |
| 方案二 | 小型 U-Net（主模型） | 3 通道输入（稀疏观测 / 观测掩码 / 房间掩码），跳连保留细节 |
| 方案三 | 插值引导残差 U-Net | 以 IDW 为先验，网络只学"插值错在哪" |
| 方案四 | U-Net（散落布点数据训练） | 与方案二严格配对，唯一变量 = 布点方式 |
| 方案五 | PG-MPR-UNet | 7 通道多先验 + IDW 残差基准 + 观测加权损失 + TTA |

两个如实记录的"负结果"（详见报告）：方案四（散落数据训练）没有带来收益；
TTA 的效果依场景而异，因此做成可开关选项。

## 快速开始

```bash
# 1) 环境（本机实测：Python 3.14.7, Apple Silicon）
python3 -m venv .venv
.venv/bin/pip install numpy matplotlib scipy openpyxl pillow torch python-docx

# 2) 第二版：训练 + 报告 + 独立校验（会覆盖 outputs/rfmap-70-30/，要保留旧结果请加 --out）
.venv/bin/python -m rfmap.holdout_experiment --epochs 180
.venv/bin/python -m rfmap.holdout_report
.venv/bin/python -m rfmap.holdout_selfcheck      # 期望：217/217 通过

# 3) 第二版：纯户型离线推理（不读实测答案）
.venv/bin/python -m rfmap.holdout_infer \
  --project outputs/rfmap-70-30/studio/sample_room.json \
  --out outputs/rfmap-70-30/inference-sample

# 4) 直接看成果（不需要任何依赖）
open outputs/rfmap-70-30/studio/index.html       # 第二版离线编辑器
open outputs/rfmap-70-30/report.html             # 第二版报告
open outputs/RF覆盖预测实验报告.html             # 第一版报告

# 5) 第一版复现：仿真 → 训练 → 评估 → 出图 → 报告
.venv/bin/python -m rfmap.simulate
.venv/bin/python -m rfmap.train_stages --device mps     # MPS 上约 12 分钟
.venv/bin/python -m rfmap.evaluate --what real --device mps
.venv/bin/python -m rfmap.figures mps
.venv/bin/python -m rfmap.report
.venv/bin/python -m rfmap.selfcheck              # 期望：26/26 通过
```

`--device` 可换成 `cpu`（慢约 60 倍）。

## 数据与坐标约定

- **坐标原点在房间内部右下角**，x 正向指向户型图**左侧**，y 正向向上。
  这一约定从几何模块一路贯穿到前端 Canvas，避免"图和现场左右镜像"。
- 唯一的实体障碍是贴墙结构柱 **0.830 m × 1.010 m**（x∈[11.813, 12.643], y∈[5.761, 6.771]）。
- 实测 RSSI 范围 **−30 ~ −51 dBm**（空房 49 点），均值 −43.286 dBm；
  其中 8 个点强于 −40 dBm，已按 BR-04 **标注但未删除**。
- 数据缺失的现象与几何完全互证：`(12, 6)` 落在结构柱内 → 该点无数据；
  `(11.7, 6)` 在柱外 0.113 m → 该点有数据（−44 dBm）。

## 实验约束（课程任务书要求）

- 只有 2.4 GHz；ESP32-C6 不支持 5 GHz。
- 采集一份地图期间，路由器位置与配置全程不动，只移动设备；
  各点统一接收高度与朝向，人退到固定位置。
- 不在 −40 ~ −70 dBm 的点**必须标注但不得删除**。
- 推理程序不读取隐藏实测点；评价只用留出的隐藏点。
- **绝不用插值结果充当实测答案** —— 报告中所有误差指标都来自隐藏实测点。
