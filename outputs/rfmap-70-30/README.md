# Wi-Fi 覆盖预测 · 双版本 70/30 实验

本次训练、验证、图表与离线编辑器全部保存在本目录。双击 `studio/index.html` 即可运行；完整结果看 `report.html`。无需联网或安装浏览器扩展。

## 使用预测器

1. 打开“户型信号预测”。导入已经裁切到户型外框的图片，填写实际宽深，或用两点实长标定比例。
2. 用“拖画墙体”描出墙、柱等固定结构，门洞留空。图片是参考底图，不自动识别墙体。
3. 输入路由器 x/y 或在画布上放置 AP。坐标原点为左下（西南）；单位米。
4. 从柜子、床、沙发、椅子、马桶、桌子、衣柜、书架、冰箱、洗衣机、浴缸、电视柜中选择并添加家具。拖动或修改坐标、宽深，可旋转或删除。
5. 点“生成整屋预测”，切换五档或连续 RSSI。可导出预测 PNG、网格 CSV 和工程 JSON。
6. “70/30 实测验证”页可切换两版数据、两种任务与五种方法，查看训练/测试点、误差、分类支持数与混淆矩阵，并导出点位和指标。

## 此次准确性

空房 49 点分为 34 训练、15 测试；有家具 140 点分为 98 训练、42 测试。总计 132/189=69.84% 训练、57/189=30.16% 测试，整数比例近似 70/30。两个版本的相同 0.2 m 数值坐标组不跨集合。

“仅户型/AP/家具”网页 U-Net：空房测试 MAE **4.467 dB**、RMSE **5.176 dB**，五档准确率 **14/15=93.33%**；家具测试 MAE **2.558 dB**、RMSE **3.271 dB**，准确率 **42/42=100%**。只统计 −70～−40 dBm 正常范围测试点时，MAE 分别 **4.946 dB（11 点）/2.443 dB（35 点）**。

**模型把这 57 个测试点全部预测为“非常好”，分类准确率与始终猜最高档相同。** 空房测试中唯一的“好”被错判；家具测试全部为最高档。数据没有一般、较差、很差样本，不能宣称五档区分能力已经验证。固定分界为 −50/−60/−70/−80 dBm；RSSI 等级不等于实际网速。

五方法×两种任务的全部指标与基线见报告。家具版 IDW 补全 MAE **1.791 dB**，优于本次五种补全网络；只户型物理趋势基线 MAE **2.186 dB**，优于网页 U-Net。网页模型是在外部测试前固定选择，内部验证偏好 AE，不能按测试成绩偷偷换成最优者。

## 训练与限制

五方法为卷积 AE、小型 U-Net、残差 U-Net、散落布点 U-Net、物理引导 PGMPR；复用已有架构家族，新增 AP/墙体/家具几何通道，宽度 8，32×32 节点。两种任务分别训练，每个模型都在 70% 内验证选轮数，再从零用全部 70% 重训。外部 30% 不参与归一化、早停、参数或模型选择。没有读取旧全点微调权重，没有把插值当真值。

- **AP 位置仍未知**：本次暂假设 (0,0)。给出实际坐标后可以保持拆分重跑；当前结果不是已知真实 AP 条件下的泛化保证。
- 只有同一房间的两版。新户型、移动路由器、家具材质变化均未独立验证。
- 家具表 120 个正数依照原规则转成负 RSSI，原始读数保留。空房 8 点、家具 32 点高于 −40 dBm，全部保留并标注偏强及饱和风险。
- 实测家具仅桌子、椅子；其余家具使用几何和假设遮挡参数，可编辑不表示已有相应材质的训练证据。
- 两版历史 x 方向说明冲突，本次按数值 x 保留、y×11.731/12 统一对齐。没有证明家具造成的因果衰减。
- 两组跨版近邻相距 0.21 m，落入同一输出节点附近且分属训练/测试；随机点留出有空间相关，不能代替隔离区域或跨房间检验。
- 本次没有连接 ESP32，也未重新确认设备健康、频段、接收高度和采样时长。

## 可复查文件

- `report.html`、`figures/`：报告、点位图、五方法连续图、五档图、混淆矩阵、误差对比及训练曲线。
- `all_points.csv`、`train_points.csv`、`test_points.csv`：原始与规范化读数及固定归属。
- `split.json`、`sources.json`：划分、内部验证、来源哈希。
- `metrics.json`、`predictions.csv`：完整指标及 1890 条逐点模型预测（189 点×10 模型）；评分仅使用其中测试行。
- `models/`：20 个训练阶段的权重、训练参数、允许的点位 ID、归一化与曲线。
- `deployment/`：网页部署模型与数值对照样本；部署推理不需读取测试点。
- `independent_validation.json`：217/217 独立校验通过，包括隐藏标签扰动不改变训练、模型恢复与指标复算。

浏览器与 Python 四个几何场景的输入一致，前向最大绝对差 **0.00001526 dB**。本机浏览器实测添加马桶后成功生成 1020 个有效格点，页面报告约 32 ms；该单次时间不是性能保证。

## 复现

在项目根目录使用已有环境：

```bash
.venv/bin/python -m rfmap.holdout_experiment --epochs 180
.venv/bin/python -m rfmap.holdout_report
.venv/bin/python -m rfmap.holdout_selfcheck
```

纯户型离线推理（不读实测答案）：

```bash
.venv/bin/python -m rfmap.holdout_infer \
  --project outputs/rfmap-70-30/studio/sample_room.json \
  --out outputs/rfmap-70-30/inference-sample
```

源实现位于 `rfmap/holdout_experiment.py`、`rfmap/holdout_infer.py`、`rfmap/holdout_report.py`、`rfmap/holdout_selfcheck.py`。运行训练会覆盖本次结果目录；若要新实验保留旧结果，使用 `--out` 指定新目录。原来的 `outputs/rfmap-studio/` 和历史实验结果未改写。
