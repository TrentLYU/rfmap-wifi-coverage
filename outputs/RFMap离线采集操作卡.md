## 1. 电脑切网

1. 菜单栏 Wi-Fi → 连 **Project 5 the FIRST Group**（就是项目这台路由器）
2. 验证连对了（小米路由器的网段是 192.168.31.x，这是最可靠的判据）：

```bash

```

- 输出 `192.168.31.x` 开头 → ✅ 连对了
- 不是 → 连错网络了，换一个 Wi-Fi 再试

## 3. 布置房间（约 10 分钟）

- [ ] 路由器放在房间一个角/桌上，**位置全程不动**
- [ ] 卷尺量房间，胶带在地面贴网格点（间距 1 m；房间小就 0.5 m）
- [ ] 准备一个统一高度的垫子（如 1.0 m 高的纸箱）——**所有点都用同一个**
- [ ] ESP32 统一朝向（每次都朝同一面墙）
- [ ] ESP32 接上充电宝

**坐标约定**：路由器所在的角为原点 `(0,0)`，x 沿长墙方向、y 沿短墙方向。

---

## 4. 先看点位清单（演练一遍）

按你房间实际尺寸改数字（例：6 m × 4 m，1 m 网格）：

```bash
python3 lab-tools/rssi_survey.py --grid 0,0,6,4,1 --dry-run
```

## 5. 采集第一份地图（约 15 分钟）

```bash
python3 lab-tools/rssi_survey.py --ip 192.168.31.71 \
  --map-id ROOM-A-dp1 --room ROOM-A --height 1.0 \
  --grid 0,0,6,4,1 --seconds 20 --settle 3
```

**每个点的固定动作（全程别变）：**

1. 把 ESP32 放到该点位的垫子上（高度、朝向一致）
2. **人退到门口/房间外**（身体不要挡住设备与路由器之间）
3. 按回车 → 自动等 3 秒稳定 → 采样 20 秒
4. 记下屏幕提示的「合适 / 太近 / 偏弱」

> 中断了？**重跑同一条命令即可**，已采的点会自动跳过（断点续采）。

---

## 6. 再采两份（换部署 —— 任务书硬性要求）

| 份数 | 怎么变 | 参数 |
|---|---|---|
| 第 2 份 | 路由器挪到**另一个角/另一面墙**，其余不变 | `--map-id ROOM-A-dp2` |
| 第 3 份 | 路由器再换一个位置（或抬高/放地） | `--map-id ROOM-A-dp3` |

每份只改 `--map-id`（和路由器实际位置），命令其余部分保持一致。

## 故障处理

| 现象 | 处理 |
|---|---|
| `find_espectre.py` 找不到设备 | `python3 lab-tools/device_doctor.py`（全量体检，看 [3/3] 段结论） |
| **所有**点 RSSI 都 > -40（太近） | 房间太小/设备离路由器太近 → 把路由器挪到房间对角，网格从离路由器 1.5 m 外开始 |
| 采样全失败（n=0） | 设备掉线：检查充电宝，或插电脑 USB 重启后再拔出 |
| 拿不到 192.168.31.x 的 IP | Wi-Fi 连错了 → 回第 1 步用 IP 判据重连 |
