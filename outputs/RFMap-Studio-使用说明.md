# RF Map Studio · 家具感知版使用说明

> 离线网页：用少量实测 RSSI 点预测整间房覆盖，并通过拖放家具观察模型预测变化。
> 网站目录：`outputs/rfmap-studio/`；当前预览：`http://localhost:8765/`。

## 1. 立即体验

### 方式 A：使用已启动的本地预览

打开 `http://localhost:8765/`，点击 **“载入家具版示例（12 点）”**，再点 **“生成整屋预测”**。

### 方式 B：完全离线双击

直接双击 `outputs/rfmap-studio/index.html`。模型权重已内联在 `model_weights.js`，不需要联网、后端或安装依赖。

### 方式 C：自己启动 HTTP 服务

在项目根目录运行：

```bash
python3 -m http.server 8765 --directory outputs/rfmap-studio
```

然后访问 `http://localhost:8765/`。停止服务时结束该 Python 进程即可。

## 2. 推荐操作流程

1. **设置户型**：输入房间净宽、净高，当前计算范围最大为 12.8 × 12.8 m。
2. **标出固定结构**：添加墙体/柱体。固定结构会从房间有效区中扣除，与家具不同。
3. **摆放家具**：选择桌、椅、沙发、床或柜子，点击“添加家具”；在画布中拖动，右侧列表可改位置和尺寸。
4. **输入实测点**：单击室内空白处并填写 RSSI（dBm），也可导入 CSV。建议至少 6 个、优先 10～20 个，覆盖房间不同区域；3 个仅适合快速试算。
5. **生成预测**：选择“连续 RSSI”或“五级信号等级”，点击“生成整屋预测”。鼠标悬停可读取任意格点的预测值。
6. **做家具对照**：点击“对比‘撤掉全部家具’”。网页保持户型和测点不变，分别运行有家具与无家具两次推理，显示平均差、平均绝对差和最大绝对差。
7. **导出结果**：可保存热力图 PNG、预测网格 CSV、测点 CSV 和完整工程 JSON；工程 JSON 可再次打开继续编辑。

坐标原点在房间西南角，x 向东、y 向北，与带家具实验报告和新的五级分级图一致。

## 3. 测点 CSV 格式

UTF-8 编码，表头支持以下两种写法：

```csv
x_m,y_m,rssi_dbm
0.9,0.0,-40
5.09,3.2,-43
10.1,8.5,-47
```

也支持 `x,y,rssi` 或 `x_room,y_room,rssi_dbm`。导入时会替换当前测点；房间外、固定结构内或 RSSI 不在 −100～0 dBm 的行会被过滤。示例：

- 文件：`outputs/rfmap-studio/sample_room.json`
- 数据：来自家具版 140 个规范化实测点中选取的 12 个点，不读取其余点作为隐藏输入。

## 4. 网页真正使用的模型

| 项目 | 当前配置 |
|---|---|
| 网络 | 方案二 Small U-Net · 家具感知版 |
| 参数量 | 1,083,841 |
| 输入 | 4 通道：稀疏 RSSI、观测掩码、房间掩码、家具占据掩码 |
| 输出 | 64 × 64 单通道 RSSI，格距 0.2 m |
| 预训练 | 1200 张家具仿真训练图，200 张验证图 |
| 训练记录 | 48 轮后早停，最佳第 12 轮，最佳验证损失 0.1874249 |
| 标准化 | mean = −51.136520 dBm，std = 11.416015 dB |
| 网页权重 | **跨房间预训练权重**，不是当前房间 140 点全量微调权重 |
| 浏览器推理 | 纯 JavaScript 前向，离线执行，无 WebGL、无第三方库 |

家具区域不会被挖成“房间外”，仍可输出 RSSI。桌、椅默认使用直径 0.8 m 的圆形/椭圆形占据；沙发、床、柜子使用矩形占据。**模型没有材质输入通道**，因此这些扩展类型只是等效占据推演，不能解释成木质、金属或不同面料的精确电磁仿真。

## 5. 已完成的验证

- 示例工程初始化：12 个实测点、8 件家具，房间掩码 3697 格、观测掩码 12 格、家具掩码 96 格。
- 家具版权重可由 PyTorch 正常加载，浏览器模型参数量与权重清单一致。
- 同一输入下，纯 JS 与 PyTorch 在 3697 个有效格点上的最大绝对差为 **0.0000153 dB**。
- 将家具通道置零后，3695 个格点输出发生变化，证明家具不是只用于显示。
- `node --check` 通过，页面及 5.78 MB 权重资源经本地 HTTP 返回 200。
- 项目原回归 `python -m rfmap.selfcheck`：26/26 项通过；家具版回归：108/108 项通过。

> 已做 DOM/Canvas 逻辑冒烟测试和本地资源检查；最终视觉效果请在浏览器中人工确认。预览标签页已在本机打开。

## 6. 精度应该怎样理解

当前只有 **1 张真实家具环境地图**，不能把同房间留出结果承诺为任意新家的精度。家具版方案二预训练模型的既有结果：

| 评估场景 | RMSE |
|---|---:|
| 独立仿真常规布点（200 场景） | 4.629 dB |
| 独立仿真散落布点（200 场景） | 5.914 dB |
| 当前真实房间角块留出（6 个隐藏点） | 1.959 dB |
| 当前真实房间中心块留出（9 个隐藏点） | 1.805 dB |
| 当前真实房间家具附近留出（13 个隐藏点） | 3.702 dB |
| 当前真实房间随机 10 输入点，20 次抽样 | 4.800 ± 0.442 dB |

随机 10 点时，同一实验中的 IDW 为 4.038 ± 0.672 dB，**少量点下神经网络并不必然优于插值**。因此新家使用时务必另留若干实测点，不输入网页，用它们独立检查 MAE/RMSE；不能只观察热力图是否“看起来合理”。

“撤掉家具”对照只表示模型对家具通道的敏感性。没有同位置撤/放家具的配对实测，就不能把差值解释为真实家具造成了多少 dB 的衰减。

## 7. 重新训练与重新导出网页

完整重训会生成仿真数据、训练五个模型、评估、用 140 点微调并重建报告，耗时较长：

```bash
.venv/bin/python -m rfmap.furniture_experiment --stage all --device mps
.venv/bin/python -m rfmap.furniture_selfcheck
```

只把已有的跨房间家具版权重导出到网页：

```bash
.venv/bin/python -m rfmap.export \
  --furniture --model unet --out-dir outputs/rfmap-studio
```

如需导出当前房间 140 点微调权重，可显式增加 `--finetuned`；该版本更适合当前房间部署展示，不应默认视为新家泛化模型。

## 9. 当前边界

1. 目前支持矩形户型与矩形固定结构，不是任意多边形 CAD 户型识别。
2. 网格固定 64 × 64、0.2 m，房间宽高均不能超过 12.8 m。
3. 路由器位置不单独作为通道；其影响主要来自实测点与训练数据中的空间分布先验。
4. 家具只输入二值占据，不含材质、高度、精确外形、多径或天线方向图。
5. 浏览器端不现场训练；重新训练与微调在 Python 流程中完成。
6. 预测不是实测。现场采集时仍须固定路由器、接收高度与朝向，并遵守项目采集规范。
